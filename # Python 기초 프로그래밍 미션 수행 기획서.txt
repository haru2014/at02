# Python 기초 프로그래밍 미션 수행 기획서

**프로젝트명: PyQuest – 파이썬 기초 퀴즈 게임**

**개발 유형:** Python 기반 터미널(콘솔) 퀴즈 프로그램  
**개발 방식:** 개인 프로젝트 / 단계별 기능 구현  
**개발 환경:** Python 3.10 이상, VS Code, Git, GitHub

## 1. 프로젝트 개요

### 1.1 기획 배경

Python을 처음 학습하면서 변수, 조건문, 반복문, 함수 등 기본 문법을 실제 프로그램에 적용하는 경험을 쌓고자 한다.

단순히 문법을 암기하는 것이 아니라, 사용자가 직접 퀴즈를 풀고 문제를 추가하며 결과를 저장할 수 있는 프로그램을 제작한다.

이를 통해 Python의 실행 구조를 이해하고, Git을 이용한 개발 이력 관리와 GitHub 저장소 활용 방법까지 익히는 것을 목표로 한다.

### 1.2 프로젝트 목표

- Python 기본 문법을 활용한 퀴즈 게임 구현
- 클래스 2개 이상을 활용한 객체지향 프로그래밍 학습
- JSON 파일을 이용한 퀴즈 및 점수 데이터 저장
- Git 커밋 10회 이상, 브랜치 생성·병합 실습
- GitHub 저장소 공개 및 개발 결과물 제출

### 1.3 퀴즈 주제

**주제: Python 기초 문법과 프로그래밍 용어**

선정 이유: Python을 처음 배우는 학습자로서 프로그램을 개발하는 동시에 변수, 자료형, 조건문, 반복문, 함수 등 핵심 개념을 반복 학습하기 위해 선정하였다.

## 3. 기본 퀴즈 데이터 설계

최초 실행 시 Python 기초 문법을 주제로 한 문제 5개를 제공한다.

| 번호 | 문제 | 정답 |
|---|---|---|
| 1 | Python에서 변수에 숫자 10을 저장하는 코드는? | `score = 10` |
| 2 | 여러 값을 순서대로 저장하는 대표적인 자료형은? | `list` |
| 3 | 조건에 따라 실행 여부를 결정하는 키워드는? | `if` |
| 4 | 목록의 요소를 반복 처리할 때 사용하는 문장은? | `for` |
| 5 | 함수를 정의할 때 사용하는 키워드는? | `def` |

각 문제에는 정답을 포함한 선택지 4개를 작성하며, 정답은 1~4의 번호로 관리한다.

추가 기능을 통해 사용자가 직접 새로운 문제를 등록할 수 있도록 한다.

## 4. 프로그램 기술 설계

### 4.1 사용 기술

| 기술 | 활용 목적 |
|---|---|
| Python | 프로그램 기능 구현 |
| VS Code | 코드 작성 및 실행 |
| JSON | 퀴즈와 점수 저장 |
| Git | 버전 및 변경 이력 관리 |
| GitHub | 원격 저장소 공개 및 동기화 |

별도의 외부 라이브러리는 사용하지 않고 Python 표준 라이브러리만 활용한다.

### 4.2 클래스 설계

**① Quiz 클래스 — 개별 문제 관리**

- `question`: 문제 내용
- `choices`: 4개의 선택지
- `answer`: 정답 번호
- `display()`: 문제와 선택지 출력
- `check_answer()`: 입력한 답의 정오 판정
- `to_dict()`: JSON 저장을 위한 데이터 변환

**② QuizGame 클래스 — 게임 전체 관리**

- `quizzes`: 전체 퀴즈 목록
- `best_score`: 최고 점수
- `show_menu()`: 메인 메뉴 출력
- `play_quiz()`: 퀴즈 진행
- `add_quiz()`: 새 문제 등록
- `list_quizzes()`: 문제 목록 출력
- `show_score()`: 최고 점수 출력
- `load_state()`: 파일 불러오기
- `save_state()`: 파일 저장
- `run()`: 전체 실행 흐름 관리

클래스별 책임을 구분해 코드를 구조화하고, 기능 수정과 오류 확인이 쉽도록 설계한다.

### 4.3 점수 계산 방식

전체 문제 수에 대한 정답 비율을 100점 만점으로 환산한다.

**점수 = (정답 수 ÷ 전체 문제 수) × 100**

예: 5문제 중 4문제 정답 → 80점

- 게임 종료 시 정답 수와 점수 출력
- 기존 최고 점수보다 높으면 갱신
- 아직 게임 기록이 없으면 '기록 없음' 출력
- 최고 점수와 해당 정답 수를 JSON에 저장

### 4.4 데이터 저장 설계

프로젝트 루트의 `state.json`에 UTF-8로 저장한다.

**저장 필드**

- `quizzes`: 퀴즈 데이터 목록
- `best_score`: 최고 점수(0~100, 최초에는 null)
- `best_correct`: 최고 점수 획득 시 정답 수
- `best_total`: 최고 점수 획득 시 전체 문제 수

저장 시 `json.dump()`와 `ensure_ascii=False`를 이용해 한글 데이터도 읽기 쉽게 관리한다.

프로그램을 종료하고 다시 실행해도 추가한 문제와 최고 점수를 유지한다.

## 5. 입력 및 오류 처리 계획

안정적인 실행을 위해 다음 상황을 처리한다.

| 상황 | 처리 방법 |
|---|---|
| 공백 포함 입력 (` 1 `) | 앞뒤 공백 제거 후 처리 |
| 문자 입력 (`abc`) | 숫자 입력 안내 후 재입력 |
| 메뉴 범위 초과 (`9`) | 1~5 입력 안내 |
| 잘못된 정답 번호 (`0`) | 1~4 재입력 안내 |
| 빈 입력 | 입력 필요 메시지 출력 |
| Ctrl+C / EOF | 가능한 범위에서 저장 후 안전하게 종료 |
| JSON 파일 없음 | 기본 퀴즈 5개로 시작 |
| JSON 파일 손상 | 오류 안내 후 기본 데이터 복구 |
| 파일 저장 실패 | 오류 메시지 출력 및 프로그램 중단 방지 |

예외 처리에는 `try/except`를 활용한다.
